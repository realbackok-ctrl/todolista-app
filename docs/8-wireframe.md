## 네비게이션 구조 개요

### 화면 맵

```
[비인증 영역]
  ├── 로그인 페이지 (LoginPage)       → 회원가입 링크
  └── 회원가입 페이지 (RegisterPage)  → 로그인 링크

[인증 영역] - 하단 탭 바 공통 표시
  ├── 할일 목록 페이지 (TodoListPage)     [탭 1: 홈]
  │     └── 할일 상세/수정 페이지 (TodoDetailPage)
  ├── 카테고리 관리 페이지 (CategoryPage) [탭 2: 카테고리]
  └── 계정 설정 페이지 (AccountPage)     [탭 3: 계정]
```

### 공통 네비게이션 컴포넌트

**상단 헤더 (인증 영역 공통)**
- 좌측: 앱 로고 + "TodoList" 텍스트
- 우측: 로그아웃 버튼 (텍스트 또는 아이콘)

**하단 탭 바 (인증 영역 공통, 모바일 기준)**
- 탭 1: 홈 아이콘 + "할일" 레이블
- 탭 2: 태그 아이콘 + "카테고리" 레이블
- 탭 3: 사람 아이콘 + "계정" 레이블
- 현재 활성 탭은 색상(파란색 계열)으로 강조

**인증 화면 (LoginPage, RegisterPage)**
- 상단 헤더 없음
- 하단 탭 바 없음

### UI 설명 및 인터랙션 노트

- **레이아웃:** 화면 중앙 수직 정렬. 상하 여백을 균등하게 배분하여 시각적 균형 확보.
- **앱 로고/타이틀:** 상단 여백 후 앱 아이콘(체크 아이콘)과 앱명 "TodoList", 부제목을 표시. 브랜드 인지도 강화.
- **이메일 입력 필드:** `type="email"` 속성 적용. 포커스 시 테두리 파란색으로 변경. 잘못된 형식 입력 시 필드 하단에 인라인 에러 메시지 표시 ("올바른 이메일 형식을 입력해주세요.").
- **비밀번호 입력 필드:** `type="password"` 속성 적용. 우측에 표시/숨김 토글 아이콘(눈 모양) 배치.
- **로그인 버튼:** Primary 버튼 (파란색 배경, 흰색 텍스트). 전체 너비(full-width). 이메일/비밀번호 미입력 시 비활성화(disabled) 상태.
- **에러 처리:** 이메일 또는 비밀번호 불일치(401) 시 폼 상단에 인라인 에러 배너 표시 ("이메일 또는 비밀번호가 올바르지 않습니다.").
- **회원가입 링크:** 하단 텍스트 링크. 탭/클릭 시 RegisterPage로 이동.
- **접근성:** 각 입력 필드에 `<label>` 연결. 에러 메시지는 `role="alert"` 적용.

### UI 설명 및 인터랙션 노트

- **레이아웃:** 로그인 페이지와 동일한 중앙 정렬 구조. 디자인 일관성 유지.
- **이메일 입력 필드:** 이미 등록된 이메일 입력 시(409 Conflict) 필드 하단에 "이미 사용 중인 이메일입니다." 인라인 에러 표시.
- **비밀번호 입력 필드:** 8자 미만 입력 후 포커스 이탈 시 힌트 텍스트가 에러 메시지로 전환("8자 이상 입력해주세요."). 우측 표시/숨김 토글 아이콘 배치.
- **비밀번호 확인 필드:** 비밀번호와 불일치 시 실시간으로 "비밀번호가 일치하지 않습니다." 에러 메시지 표시.
- **회원가입 버튼:** Primary 버튼. 전체 너비. 모든 필드가 유효할 때만 활성화.
- **로그인 링크:** 하단 텍스트 링크. 탭/클릭 시 LoginPage로 이동.
- **성공 처리:** 회원가입 성공 시 자동으로 로그인 처리 후 TodoListPage로 리디렉션.
- **접근성:** 각 입력 필드에 `<label>` 연결. 비밀번호 힌트 텍스트는 `aria-describedby`로 연결.

### UI 설명 및 인터랙션 노트

**공통**
- **상태 필터:** "전체 / 미완료 / 완료" 3가지 탭 또는 라디오 버튼 그룹. 선택 시 목록 즉시 갱신 (페이지 이동 없음). 기본값: "전체".
- **카테고리 필터 (모바일):** 드롭다운 셀렉트 박스. "전체" 선택 시 필터 해제.
- **카테고리 필터 (데스크탑):** 좌측 사이드 패널에 체크박스 목록으로 표시.
- **할일 카드:** 클릭 시 TodoDetailPage로 이동. 체크박스 클릭 시 상태 토글(PENDING ↔ COMPLETED), 카드 클릭 시 상세 이동, 삭제 버튼 클릭 시 확인 다이얼로그 후 삭제.
- **완료 토글:** 체크박스 클릭 시 즉시 API 호출 후 카드 스타일 갱신. 성공 시 낙관적 업데이트(optimistic update) 적용.
- **삭제 확인:** 삭제 버튼 클릭 시 "정말 삭제하시겠습니까?" 확인 모달 또는 브라우저 `confirm()` 다이얼로그 표시.

**모바일 전용**
- **FAB (Floating Action Button):** 우측 하단 고정 위치. 원형 버튼(56px), 파란색 배경, 흰색 "+" 아이콘. 탭 시 TodoDetailPage(생성 모드)로 이동.
- **카드 스와이프:** Phase 2 고려사항. Phase 1에서는 카드 내 버튼으로만 액션 처리.

**데스크탑 전용**
- **사이드 패널:** 좌측 고정 너비(약 240px). 필터와 할일 요약 정보 표시.
- **새 할일 추가 버튼:** 목록 영역 최상단. 클릭 시 TodoDetailPage(생성 모드)로 이동.
- **할일 요약 섹션:** 전체/미완료/완료/기한초과 건수 실시간 표시.

**Overdue 시각화 (FR-TODO-02 Overdue 식별 규칙)**
- `dueDate < 현재 시각` AND `status = PENDING`인 항목을 클라이언트에서 판단하여 빨간 스타일 적용.

**위험 구역 섹션 (FR-AUTH-04)**
- **시각적 구분:** 빨간색 테두리(`border-red-200`) 경고 박스. "위험 구역" 섹션 레이블은 빨간색 텍스트. 경고 아이콘(⚠) 동반.
- **경고 문구:** 데이터 영구 삭제에 대한 명확한 경고 문구 표시.
- **탈퇴 버튼:** Destructive Primary 버튼(빨간 배경). 클릭 시 확인 모달 표시.
- **탈퇴 확인 모달:** 이메일 재입력으로 의도치 않은 탈퇴 방지. 입력한 이메일이 현재 로그인 이메일과 일치할 때만 "탈퇴 확인" 버튼 활성화. 탈퇴 성공 시 모든 데이터 삭제 후 LoginPage로 리디렉션.
- **계정 탭 활성:** 하단 탭 바에서 "계정" 탭이 파란색으로 강조 표시.

### 접근성 기준 (WCAG 2.1 AA)

- **색상 대비:** 텍스트와 배경 대비 비율 최소 4.5:1 준수
- **터치 타겟:** 모든 인터랙티브 요소 최소 44x44px 확보
- **레이블 연결:** 모든 `<input>`, `<select>`, `<textarea>`에 `<label>` 또는 `aria-label` 연결
- **에러 메시지:** `role="alert"` 또는 `aria-live="polite"` 적용으로 스크린 리더 감지
- **키보드 탐색:** Tab 순서 논리적으로 구성, 포커스 인디케이터 visible 유지
- **상태 아이콘:** 아이콘 단독 사용 시 `aria-label` 또는 인접 텍스트로 보완 (예: ⚠ 아이콘에 "기한 초과" 텍스트 병기)
